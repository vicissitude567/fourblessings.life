# 今天也很好 (Today Is Good) — Design Spec

## 概述

一个极简的"生活好事收集器"H5应用。她每天花30秒记录一件好事，日积月累变成色卡日历。焦虑时翻开，用事实告诉自己"我一直都很好"。

## 核心体验

- **每日记录**：一句话 + 可选照片 + 心情颜色，每晚9:30微信提醒
- **月度色卡**：按日历视图展示，每天一个色块，点击看详情
- **好事罐**：所有记录可滚动回看
- **你的留言**：你也可以悄悄写鼓励放进她的罐子里

## 技术方案

- **前端**：纯静态 H5，暖纸手账风格，PWA可添加到桌面
- **后端**：Node.js 轻量 API（存储日记 + 定时邮件推送）
- **通知**：QQ邮箱 → 微信提醒（她绑定QQ邮箱微信通知）
- **部署**：独立域名或子路径，与 fourblessings.life 隔离

## 数据模型

- 日记条目：{ date, text, photo_url, color, source(她/你) }
- 用户：{ name, email, password_hash, notification_enabled }

## 页面

1. 首页 — 今日记录入口 + 月历色卡预览
2. 记录页 — 输入框 + 颜色选择器 + 图片上传
3. 回看页 — 月历视图 + 历史浏览
4. 管理页 — 你的写信入口（需密码）
